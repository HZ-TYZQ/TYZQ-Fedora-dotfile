# 床下有罐钱 · 半透明

Fcitx5 Classic UI 横排候选主题，第二版细化预览。暖炭灰半透明底色、蜂蜜金选中项与原尺寸点赞角色。

## 本次细化

- 暖白正文、暖灰序号与浅金选中项，统一菜单与翻页图标。
- 细描边、轻阴影和更舒展的文字留白。
- 角色以独立的 120 × 144 PNG Overlay 贴在右下角，候选框伸缩时不拉伸人物。
- 两个目录保留各自主题名称，使用同一套视觉规格。

## 先看预览

从项目根目录用浏览器打开 `preview/index.html`，或运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/preview/ ，可以切换深浅背景、日常输入、长候选词和单行候选，点击候选词查看高亮。

预览复用主题 SVG、九宫格切片边距和角色 PNG；候选字体模拟本机「荆南麦圆体 17」在 96 DPI 下的尺寸。网页为效果示意，实际文字排布与窗口尺寸仍以 Fcitx5、应用和显示缩放为准。当前预览不会修改桌面配置。

## 安装

确认效果后，从项目根目录执行（已有同名主题请先备份）：

```sh
mkdir -p ~/.local/share/fcitx5/themes
cp -r theme/bed-money ~/.local/share/fcitx5/themes/
```

在 Fcitx5 的「附加组件 → 经典用户界面」中选择「床下有罐钱 · 半透明」。建议使用横排候选列表，候选字体约 17 pt。人物素材为 1× 原尺寸，极小字体和分数缩放需要在实际桌面检查。

维护切片或 Overlay 配置时可参考 [Fcitx5 官方主题定义](https://github.com/fcitx/fcitx5/blob/master/src/ui/classic/theme.h)。
